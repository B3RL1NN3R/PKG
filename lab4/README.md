# RasterLab

Qt desktop application for rasterization of lines, circles and curves using basic raster graphics algorithms.

## Download
Windows version:

[Download RasterLab v1.0.0](https://github.com/B3RL1NN3R/PKG/releases/tag/RasterLab)

## Features

- Line rasterization algorithms: Step-by-Step, DDA and Bresenham
- Circle rasterization using Bresenham's algorithm
- Wu's algorithm for anti-aliased line rendering
- Castle-Pitteway algorithm for rasterization of conic sections and arcs
- Virtual raster implemented as a two-dimensional array of pixel flags
- Support for all eight octants when drawing line segments
- Performance benchmarking: 100,000 line segments and 50,000 circles
