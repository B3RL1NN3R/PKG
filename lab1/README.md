# ColorConverter

Qt desktop application for converting colors between RGB, CMYK and HLS models.

## Download

Windows version:

[Download ColorConverter v1.0.0](https://github.com/B3RL1NN3R/PKG/releases/tag/ColorConverter)

## Features

- RGB ↔ CMYK ↔ HLS conversion
- Interactive sliders
- Manual input with validation
- Automatic mathematical tests
