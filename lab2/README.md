# ImageMetadataReader

Qt desktop application for reading metadata from JPG, GIF, TIFF, BMP, PNG and PCX image files.

## Download

Windows version:

[Download ImageMetadataReader v1.0.0](https://github.com/B3RL1NN3R/PKG/releases/tag/ImageMetadataReader)

## Features

- JPG, GIF, TIFF, BMP, PNG and PCX support
- Manual metadata parsing without third-party libraries
- Image size, DPI, color depth and compression reading
- Multithreaded folder scanning with progress bar
- Corrupted file detection
- Automatic parser tests
