# ImageProcessor

Desktop application for low-frequency filtering and morphological image processing.

## Download              
Windows version:

[Download ImageProcessor v1.0.0](https://github.com/B3RL1NN3R/PKG/releases/tag/ImageProcessor)
              
## Features              

- Box and Gaussian low-frequency filters with separable convolutions
- Morphological operations: erosion, dilation, morphological gradient, Top-Hat and Black-Hat
- Honest pixel access through direct memory work without high-level methods
- Edge handling strategies: Clamp (border replication) and Reflect (mirror reflection)
- Save processed results in PNG, JPEG and BMP formats
- Automatic parser tests
